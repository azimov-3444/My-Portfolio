# My Portfolio - Humoyun Azimov

A professional, recruiter-grade **Full-Stack Developer Portfolio & Telegram Portfolio Bot System** built with **React, Node.js, Express, and Tailwind CSS**.

## 🌟 Key Features

- **Real Projects Showcase**:
  1. [999 Premium Tools](https://999premiumtools.com/) *(Commercial Jewelry Equipment Platform)*
  2. [LUMOS SCHOOL](https://lumos-school.vercel.app/) *(Modern Education Platform)*
  3. [FateLeaf: Tea & Destiny](https://frontend-six-mu-9i5b5beol6.vercel.app/) *(Interactive Web Application)*
  4. [Frontend Showcase](https://magenta-conkies-e014b0.netlify.app/) *(UI Component Showcase)*
- **Multilingual Support**: Switch seamlessly between **O'zbek tili (UZ)** and **Русский (RU)**.
- **Theme Switcher**: Apple/Stripe-inspired **Light Mode ☀️** & Obsidian **Dark Mode 🌙**.
- **Full-Stack Node.js Backend**: Express REST API (`/api/projects`, `/api/skills`, `/api/profile`, `/api/contact`).
- **Telegram Bot Integration**: Responds to user queries and forwards portfolio contact form messages directly to Telegram!

---

## 🛠 Tech Stack

- **Frontend**: React 18, JSX, JavaScript ES6+, Tailwind CSS, Vite, Lucide Icons
- **Backend**: Node.js, Express.js, Nodemon, CORS, Dotenv
- **Bot**: `node-telegram-bot-api`

---

## 🚀 Getting Started

### 1. Installation
```bash
npm run install:all
```

### 2. Run Development Servers
```bash
# Run both Frontend (Port 3000) & Backend (Port 5000) concurrently
npm run dev
```

### 3. Run Backend Only
```bash
cd server
npm run dev
```

### 4. Run Frontend Only
```bash
cd client
npm run dev
```
